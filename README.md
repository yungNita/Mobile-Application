# Login and Registration UI in Flutter
## Objective
Students will design and implement a Login and Registration UI in Flutter using basic widgets such as TextField, ElevatedButton, and Checkbox.

## Task Requirements
### 1. Create a Flutter Project
Use the following command to create the project:
- flutter create login_ui
- Open the project in VS Code or Android Studio.

### 2. Design the Login Screen
The entire project should use the Lato font.
Include the following elements:
- Email & Password fields
- "Remember Me" Checkbox
- "Login" button
- "Login with Google" button
- "Register" link for navigation

### 3. Design the Registration Screen
Include the following elements:
- mail, Password, and Confirm Password fields
- Terms & Conditions Checkbox
- "Register" button
- "Login" link for navigation

### 4. Navigation Between Screens
- Clicking "Register" should navigate to the Registration Page.
- Clicking "Login" should navigate back to the Login Page.
